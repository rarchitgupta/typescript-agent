# TypeScript MVP Starter

Use this starter to build a small full-stack MVP with Codex.

1. Write your initial requirements in [docs/notes.txt](docs/notes.txt).
2. Ask Codex to draft `docs/PRD.md`, aiming for five minutes. Answer clarifying questions and approve the draft when ready.
3. Ask Codex to implement the first behavior slice and run its focused unit tests.

See [AGENTS.md](AGENTS.md) for the agent workflow.
